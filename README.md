## Coffee Shop Website

A modern, responsive coffee shop website built using **HTML, CSS, and JavaScript**.  
This project is designed to provide a clean and user-friendly experience for showcasing a coffee shop menu, services, and contact details.

## Features

- ☕ Modern and clean UI design  
- 📱 Fully responsive design (mobile, tablet, desktop)  
- 🍽️ Interactive menu section  
- 🎨 Smooth hover effects and animations  
- 📍 Contact section with location details  
- ⚡ Lightweight and fast performance  
- 🧑‍💻 Built using pure HTML, CSS, and JavaScript (no frameworks)

## Technologies Used

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)
